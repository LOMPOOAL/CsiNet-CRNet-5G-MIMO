# Code source du mémoire - LOMPO Abdoul Karim

Ce dépôt contient le code MATLAB utilisé pour le mémoire :

**"Compression et Reconstruction du CSI pour Massive MIMO 5G par Autoencodeurs Profonds"**

---

## 📂 Contenu du dépôt

- `createCsiNet.m` : Architecture de l'autoencodeur CsiNet
- `createCRNet.m` : Architecture de l'autoencodeur CRNet avec branches parallèles
- `create_and_test_models.m` : Création des modèles et test de passage avant
- `tester_tous_les_codes.m` : Test de l'ensemble des fonctions MATLAB
- Autres fonctions auxiliaires.

---

## ⚙️ Instructions d'utilisation

1. Ouvrir **MATLAB R2024a** ou version ultérieure.
2. Ajouter ce dossier au path de MATLAB.
3. Exécuter le script `tester_tous_les_codes.m` pour valider le bon fonctionnement.
4. Les Toolboxes requises sont :
   - 5G Toolbox
   - Deep Learning Toolbox
   - Statistics and Machine Learning Toolbox
